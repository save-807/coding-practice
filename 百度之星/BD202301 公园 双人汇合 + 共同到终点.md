
````text
双人汇合 + 共同到终点：三次 BFS 模板

1. 题型特征

这类题通常具有以下特点：

两个人从不同起点出发
最终目标点相同
两个人单独移动有各自的花费
两个人会合后一起移动，可以减少花费
图是无权图

核心思路：

枚举两个人在哪一个点会合。



2. 枚举会合点

假设两个人在点 x 会合。

整个移动过程可以拆成三段：

T ------> x
           \
            ------> N
           /
F ------->
````

分别是：

1. 第一个人：`T -> x`
    
2. 第二个人：`F -> x`
    
3. 两个人一起：`x -> N`
    

因此只需要知道三个最短距离：

```text
distT[x]：T 到 x 的最短距离
distF[x]：F 到 x 的最短距离
distN[x]：x 到 N 的最短距离
```

---

## 3. 花费公式

假设：

```text
TE：第一个人单独走一步的花费
FE：第二个人单独走一步的花费
S ：两个人一起走一步时减少的花费
```

两个人一起走一步的总花费为：

$$  
TE + FE - S  
$$

如果选择在 `x` 会合，那么总代价为：

$$  
\boxed{  
distT[x] \times TE  
+  
distF[x] \times FE  
+  
distN[x] \times (TE + FE - S)  
}  
$$

枚举所有：

$$  
x = 1,2,\dots,N  
$$

取最小值即可。

---

## 4. 为什么会合之后不用再分开？

因为两个人最终目标都是同一个点 `N`。

分开走一步的总花费：

$$  
TE + FE  
$$

一起走一步的总花费：

$$  
TE + FE - S  
$$

因为：

$$  
S > 0  
$$

所以：

$$  
TE + FE - S < TE + FE  
$$

因此：

> 两个人一旦会合，之后一直一起走一定不会更差。

所以只需要考虑：

```text
会合前：各走各的
会合后：一直一起走到终点
```

不需要考虑：

```text
会合 -> 分开 -> 再会合
```

---

## 5. 为什么跑三次 BFS？

因为图是无权图。

无权图最短路使用：

```text
BFS
```

分别从三个关键点出发：

```cpp
auto distT = bfs(T);
auto distF = bfs(F);
auto distN = bfs(N);
```

得到：

```text
distT[i]：T 到 i 的最短距离
distF[i]：F 到 i 的最短距离
distN[i]：N 到 i 的最短距离
```

如果是无向图：

$$  
dist(x,N)=dist(N,x)  
$$

所以从 `N` BFS 一次，就可以得到所有点到 `N` 的距离。

## 6. BFS 模板

```cpp
vector<int> bfs(int start) {
    vector<int> dist(n + 1, -1);
    queue<int> q;

    dist[start] = 0;
    q.push(start);

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (int v : g[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }

    return dist;
}
```

## 7. 主逻辑模板

```cpp
auto distT = bfs(T);
auto distF = bfs(F);
auto distN = bfs(N);

long long ans = LLONG_MAX;

for (int x = 1; x <= n; x++) {

    // 三段路必须都能走通
    if (distT[x] == -1 ||
        distF[x] == -1 ||
        distN[x] == -1) {
        continue;
    }

    long long cost =
          1LL * distT[x] * TE
        + 1LL * distF[x] * FE
        + 1LL * distN[x] * (TE + FE - S);

    ans = min(ans, cost);
}

if (ans == LLONG_MAX)
    cout << -1;
else
    cout << ans;
```

## 8. 复杂度

一次 BFS：

$$  
O(N+M)  
$$

三次 BFS：

$$  
O(3(N+M))  
$$

忽略常数：

$$  
\boxed{O(N+M)}  
$$

枚举所有会合点：

$$  
O(N)  
$$

所以总时间复杂度：

$$  
\boxed{O(N+M)}  
$$

空间复杂度：

$$  
\boxed{O(N+M)}  
$$

## 9. 做题识别关键词

以后看到下面这些关键词：

```text
两个人
不同起点
相同终点
一起走更便宜
求最小总费用
```

优先考虑：

> 枚举会合点 + 分段最短路

### 无权图

使用：

```text
BFS
```

### 带权图

使用：

```text
Dijkstra
```

---

## 10. 一句话总结

> 两人从不同起点前往同一终点，并且会合后一起走更便宜时，可以枚举会合点 `x`，分别计算两个起点到 `x` 的最短路，以及 `x` 到终点的最短路，再计算总代价取最小值。无权图使用三次 BFS，带权图可以使用三次 Dijkstra。
