## 二、函数

### 1. 形参与实参

函数定义中小括号内的参数称为形参，调用函数时传入的参数称为实参。

### 2. 函数的分文件编写

**作用：让代码结构更加清晰。

编写步骤：

1. 创建扩展名为 `.h` 的头文件。
2. 创建扩展名为 `.cpp` 的源文件。
3. 在头文件中编写函数声明。
4. 在源文件中编写函数定义。

## 三、指针

### 1. 指针与内存地址

指针变量用于保存内存地址。

### 2. 空指针和野指针

- **空指针：指针变量指向内存中编号为 `0` 的空间。
- **用途：初始化指针变量。
- **注意：空指针指向的内存不可以访问。

- **野指针：地址未知或已经失效
```cpp
//情景一：
int* p;
*p = 10;  // 错误：p 指向哪里并不知道
//情景二：
int* p = new int(10);
delete p;
cout << *p;  // 错误：p 指向的内存已经释放
```
