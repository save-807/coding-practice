
# 一、软件测试分类
- **知道一个软件系统常常做哪些测试
# 二、按阶段划分
- **1.单元测试 ：针对程序源代码的测试（开发）
- **2.集成测试：针对功能模块组装的测试
- **3.系统测试：针对整个系统（功能、非功能）进行测试
- **4.验收测试：以用户身份验证系统是否满足需求（用户）
# 三、按代码可见度划分
- **1.黑盒测试：针对UI界面软件系统输入输出类测试
- **2.灰盒测试：针对无UI界面软件系统输入输出和内部逻辑结构的测试（能看懂部分源代码）
- **3.白盒测试：针对程序源代码及内部逻辑本身进行测试
# 四、其他划分
- **1.冒烟测试：保障提测软件具备可测性
- **2.回归测试：对已修复功能再次测试\更新需求后对已有功能有没有负面影响进行测试
